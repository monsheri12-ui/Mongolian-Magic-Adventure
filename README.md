# По следам магии

Интерактивное чтение «Гарри Поттер и философский камень» на монгольском: первые десять глав, 1330 последовательных отрывков.

[Открыть игру](https://monsheri12-ui.github.io/Mongolian-Magic-Adventure/)

- Три уровня: начальный, средний и оригинал предоставленного монгольского перевода. Две учебные версии передают события и детали соответствующего отрывка более простыми предложениями.
- Перевод, карточки отдельных слов, словарные формы и цветной разбор грамматики.
- Озвучка всех 3990 вариантов чтения; прослушивание отрывка целиком или отдельного предложения, настройка скорости.
- Личный словарь, карточки и упражнения на перевод в обе стороны.
- 360 вопросов на понимание: по 12 для каждого уровня каждой главы. Ответы и объяснения открываются после попытки.
- Хроника с поиском, прогресс каждой главы в процентах, сохранение в браузере и перенос прогресса отдельным файлом.

## Запуск и сохранение

Игра работает на GitHub Pages и встраивается в страницу Тильды. Для локального запуска распакуйте файлы в одну папку, запустите `python3 -m http.server 8000` и откройте `http://localhost:8000`. Открытие `index.html` через `file://` не поддерживается.

Тексты и словари загружаются частями из файлов, перечисленных в `chapter.json`. Записи заранее подготовлены и хранятся в `audio-pack-*.bin`; `audio.json` содержит границы MP3 и интервалы предложений. Во время чтения текст не отправляется сервису синтеза речи.

Сохранённые слова остаются связаны с тем текстом, из которого были добавлены. Файлы `history-*.json` содержат прежние учебные формулировки для совместимости карточек. Личного словаря, результатов тестов и данных читателей в репозитории нет: они хранятся в браузере читателя.

## Материалы

Автор книги — Дж. К. Роулинг. Монгольский оригинал взят из предоставленного владельцем проекта PDF. Учебные адаптации, русские пояснения и вопросы подготовлены для этой игры. Для уточнения грамматики используются Kullmann–Tserenpil, *Mongolian Grammar* (2008), и монгольский толковый словарь. Иллюстрации созданы для проекта в рисованном стиле. Голос — Microsoft Yesui (`mn-MN-YesuiNeural`).

Права на книгу и перевод принадлежат их правообладателям; репозиторий не предоставляет на них открытую лицензию. Значки Lucide распространяются по лицензии ISC; уведомления сохранены в файле библиотеки и `THIRD_PARTY_NOTICES.txt`.
