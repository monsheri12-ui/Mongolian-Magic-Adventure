# По следам магии

Интерактивное чтение «Гарри Поттер и философский камень» на монгольском: все 17 глав, 2284 последовательных отрывка.

[Открыть игру на Тильде](https://foxsaywawa.tilda.ws/mongolian-magic-chapter-1) · [Открыть на GitHub Pages](https://monsheri12-ui.github.io/Mongolian-Magic-Adventure/)

- Три уровня чтения: начальный, средний и продвинутый; на продвинутом уровне используется монгольский оригинал.
- Русский перевод, карточки слов и цветной разбор грамматики.
- Озвучка всех 6852 вариантов чтения, прослушивание отдельных предложений и настройка скорости.
- Личный словарь, карточки для повторения и упражнения на перевод в обе стороны.
- 612 вопросов на понимание: по 12 для каждого уровня каждой главы. Ответы и объяснения открываются после попытки.
- Хроника с поиском, отдельный прогресс каждой главы и перенос сохранений файлом.

## Запуск и сохранение

Для локального запуска сохраните игровые файлы в одной папке, выполните `python3 -m http.server 8000` и откройте `http://localhost:8000`. Запуск через `file://` не поддерживается: игра загружает тексты, словари и аудио частями.

Прогресс чтения, словарь и результаты тестов сохраняются в браузере. В разделе «Сохранить или перенести прогресс» можно скачать сохранение и загрузить его на другом устройстве. Перед импортом рекомендуется скачать копию имеющегося прогресса: импорт заменяет текущее сохранение.

Озвучка заранее подготовлена и воспроизводится из игровых файлов; во время чтения текст не отправляется сервису синтеза речи. Сохранённые слова остаются связаны с той редакцией отрывка, из которой были добавлены.
