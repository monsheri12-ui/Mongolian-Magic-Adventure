# По следам магии

Интерактивное чтение «Гарри Поттер и философский камень» на монгольском.
**Две полные главы: 303 последовательных отрывка.**

- Глава 1. Мальчик, который выжил: 211 отрывков, 400 предложений.
- Глава 2. Исчезнувшее стекло: 92 отрывка, 264 предложения.

- Три уровня: две учебные адаптации и оригинал предоставленного монгольского перевода.
- Контекстный словарь, разбор форм, цветное выделение грамматики и повторение слов.
- Монгольская озвучка обеих глав голосом Microsoft Yesui (mn-MN-YesuiNeural): 909 версий отрывков; 904 уникальных MP3, около 111 минут. Вторая глава — 276 записей, около 40 минут, 674 фрагмента для прослушивания отдельных предложений.
- 72 авторских вопроса на понимание: по 12 для каждого уровня каждой главы. Объяснение и подтверждающий отрывок появляются после ответа.
- Поиск по хронике, прогресс главы в процентах, локальное сохранение и перенос JSON.

## Запуск

Откройте игру на GitHub Pages. Для локального запуска нужен обычный HTTP-сервер, например `python3 -m http.server 8000`. Затем откройте `http://localhost:8000`. Двойной щелчок по index.html не подходит: браузер ограничивает загрузку файлов через file://.

Все файлы публикации находятся в корне. Сервер приложений, API-ключи и внешние запросы для синтеза речи во время чтения не нужны. MP3 заранее подготовлены и упакованы без изменения байтов в audio-pack-*.bin; audio.json содержит границы записей и интервалы предложений, полученные от синтезатора. Браузер загружает нужный пакет и воспроизводит выбранную MP3-запись. В адрес пакета включена его контрольная сумма, поэтому старая версия из кэша не подменит обновлённый файл.

Прогресс хранится только в браузере читателя. Экспорт создаёт отдельный файл пользователя; в репозитории нет личного словаря или прогресса.

## Содержание и происхождение

Книга: Дж. К. Роулинг. Монгольский текст первых двух глав взят из PDF, предоставленного владельцем проекта: глава 1 — страницы 5–17, глава 2 — страницы 18–26. Оригинал идёт последовательно; исправлены только разрывы слов текстового слоя и латинская Y вместо Ү. Вероятные опечатки самого издания поясняются в карточках. Учебные адаптации, русские объяснения и вопросы созданы для этого проекта. Иллюстрации созданы с помощью генеративной модели и выдержаны в едином рисованном стиле.

Озвучка второй главы добавлена после отдельного разрешения владельца проекта на передачу её монгольского текста и двух учебных адаптаций Microsoft Edge TTS.

Озвучка синтетическая, не запись диктора. Текст для синтеза точно совпадает с соответствующим уровнем чтения. Особенности и вероятные опечатки предоставленного оригинала сохранены; автоматический голос может произносить отдельные имена и такие места неточно. Независимая проверка произношения носителем не проводилась.

Права на книгу и перевод принадлежат их правообладателям; репозиторий не предоставляет на них открытую лицензию. Библиотека значков Lucide распространяется по ISC; уведомления сохранены в lucide.min.js. Озвучка создана через edge-tts 7.2.8 с разрешения владельца проекта на обработку текстов сервисом Microsoft Edge TTS.

Исходные байты и интервалы первой главы сохранены. Проверены контрольные суммы всех 18 аудиопакетов и 1813 интервальных меток предложений.
- Проверены воспроизведение, пауза, отдельные предложения, скорость 0,75× и остановка при смене сцены/уровня.
- Проверены все 36 новых вопросов второй главы; сохранены 36 вопросов первой главы. Проверены смешанный результат, сохранение по уровням, ссылки на отрывки, импорт без частичной перезаписи при ошибке.
- Проверены ширины 1100, 736 и 320 px, естественные пропорции иллюстраций и отсутствие горизонтальной прокрутки.

- Все 276 версий новых отрывков проверены в браузере.
- Проверены переход между главами, независимые проценты, поиск по главе и перенос результатов старого теста в главу 1.
- В русских переводах, пояснениях и тестах используется имя Гарри; монгольское написание Харри сохранено.

Глава 2 использует десять новых иллюстраций: отдельный утренний вид дома и семейные фотографии на камине, кладовка днём и ночью, кухня с подарками, машина, школьный двор, зоопарк, террариум и выход удава. Первые четыре отрывка используют свои картинки, соответствующие тексту второй главы.
