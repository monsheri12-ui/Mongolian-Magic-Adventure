**Пять полных глав: 668 последовательных отрывков.**

- Глава 2. Исчезнувшее стекло: 92 отрывка, 264 предложения.

- Глава 4. Хранитель ключей: 98 отрывков, 392 предложения.

- Контекстный словарь, разбор форм, цветное выделение грамматики и повторение слов.
- Монгольская озвучка всех пяти глав голосом Microsoft Yesui (mn-MN-YesuiNeural): 2004 версии отрывков; 1999 уникальных MP3, около 291 минуты. Вторая глава — 276 записей, около 40 минут, 674 фрагмента для прослушивания отдельных предложений.

- Поиск по хронике, прогресс главы в процентах, локальное сохранение и перенос JSON.

## Запуск

Откройте игру на GitHub Pages. Для локального запуска нужен обычный HTTP-сервер, например `python3 -m http.server 8000`. Затем откройте `http://localhost:8000`. Двойной щелчок по index.html не подходит: браузер ограничивает загрузку файлов через file://.

Все файлы публикации находятся в корне. Данные отрывков разделены на scenes-*.json; chapter.json содержит словарь, метаданные и порядок частей. При запуске игра собирает из них прежний формат данных, сохраняя номера отрывков и совместимость прогресса. Сервер приложений, API-ключи и внешние запросы для синтеза речи во время чтения не нужны. MP3 заранее подготовлены и упакованы без изменения байтов в audio-pack-*.bin; audio.json содержит границы записей и интервалы предложений, полученные от синтезатора. Браузер загружает нужный пакет и воспроизводит выбранную MP3-запись. В адрес пакета включена его контрольная сумма, поэтому старая версия из кэша не подменит обновлённый файл.

Прогресс хранится только в браузере читателя. Экспорт создаёт отдельный файл пользователя; в репозитории нет личного словаря или прогресса.

## Содержание и происхождение

Книга: Дж. К. Роулинг. Монгольский текст первых пяти глав взят из PDF, предоставленного владельцем проекта: глава 1 — страницы 5–17, глава 2 — страницы 18–26, глава 3 — страницы 27–36, глава 4 — страницы 37–46, глава 5 — страницы 47–65. Оригинал идёт последовательно; исправлены только разрывы слов текстового слоя и латинская Y вместо Ү. Вероятные опечатки самого издания поясняются в карточках. Учебные адаптации, русские объяснения и вопросы созданы для этого проекта. Иллюстрации созданы с помощью генеративной модели и выдержаны в едином рисованном стиле.

Озвучка второй главы добавлена после отдельного разрешения владельца проекта на передачу её монгольского текста и двух учебных адаптаций Microsoft Edge TTS.

Озвучка синтетическая, не запись диктора. Текст для синтеза точно совпадает с соответствующим уровнем чтения. Особенности и вероятные опечатки предоставленного оригинала сохранены; автоматический голос может произносить отдельные имена и такие места неточно. Независимая проверка произношения носителем не проводилась.

Права на книгу и перевод принадлежат их правообладателям; репозиторий не предоставляет на них открытую лицензию. Библиотека значков Lucide распространяется по ISC; уведомления сохранены в lucide.min.js. Озвучка создана через edge-tts 7.2.8 с разрешения владельца проекта на обработку текстов сервисом Microsoft Edge TTS.
